# Movie Recommender System 🎬

A Streamlit-based movie recommendation application that provides personalized movie suggestions using content-based filtering (TF-IDF and Metadata).

## 🔗 Live Demo
**[Launch App](https://movie-recommendation-qwuqzfpc9xjhbr4vfmaana.streamlit.app/)**

## Features
- **Home Feed**: Browse trending, popular, and top-rated movies.
- **Search**: Auto-complete search for movies via the TMDB API.
- **Recommendations**:
  - Content-based filtering using TF-IDF on movie overviews.
  - Metadata-based filtering (Genres, Keywords).
- **Details**: View movie posters, backdrops, trailers, and watch providers.
- **Responsive Design**: Netflix-inspired dark UI.

## Tech Stack
- **Python**: Core logic.
- **Streamlit**: UI framework.
- **Scikit-learn**: TF-IDF vectorization and cosine similarity.
- **TMDB API**: Movie metadata and images.
